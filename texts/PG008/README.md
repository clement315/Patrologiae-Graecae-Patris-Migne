页底 *Concordantia* 脚注标出权威校订本的对照坐标。《劝勉希腊人》对应 SC 2[^sc2]，《导师》卷 I–III 分别对应 SC 70[^sc70]、SC 108[^sc108]、SC 158[^sc158]，《杂记》卷 I–IV 对应 GCS 52[^gcs52]。以下链接可用于查阅对应版次。
